# ResolveHQ — Frontend

A role-based customer support and escalation platform built with Angular and TypeScript.

ResolveHQ is a full-stack SaaS portfolio project designed to demonstrate modern frontend engineering, secure role-based workflows, API integration, testing, and production deployment.

## Project Status

**Current phase:** Phase 1 — Foundation and Architecture

The frontend application is not yet implemented. This repository is being prepared for development.

## Planned Capabilities

- Role-specific experiences for Admins, Technical Support Agents, and Customers
- Customer support ticket creation and tracking
- Ticket assignment and status management
- Customer-agent messaging and ticket activity history
- Responsive dashboards and interfaces
- Authentication integration with Auth0
- Integration with the ResolveHQ backend REST API

These are planned capabilities, not currently implemented features.

## Technology Stack

- Angular with standalone components
- TypeScript
- HTML and CSS
- Auth0 for authentication
- AWS S3 and CloudFront for planned frontend hosting
